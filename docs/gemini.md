# Gemini AI 設定と汎用フォーム解析

Google 公式の `@google/genai` をサーバーから呼び出します。Gemini は公開された規約やフォーム構造を解析し、型付きの操作計画を提案します。ブラウザを自由操作する権限は与えず、Zod とローカルの資格・同意・送信ルールが検証した操作だけを Playwright が実行します。

API キーがなくても従来のルールベース収集と `local-test` フォームは利用できます。AI を必要とする不明なフォームは、キー未設定・API 障害・上限到達時に手動確認へ移します。

## 1. 設定画面からキーを登録する

1. ローカルアプリを起動し、ダッシュボードの **設定** → **AI 設定を開く** を選びます。直接開く場合のパスは `/settings/ai` です。
2. **API キー** のパスワード入力欄へ、[Google AI Studio の API キー画面](https://aistudio.google.com/apikey)で発行したキーを貼り付け、**API キーを保存**を押します。キーをチャットへ送る必要はありません。
3. 保存後の表示は「設定済み」だけです。入力欄を再表示しても保存済みのキー全文は取得できません。API キーはブラウザの localStorage に保存しません。
4. モデル一覧の取得ボタンで、**そのキーから利用できるモデル**を取得します。取得自体もアプリ側の API 呼び出しカウンターに含まれます。
5. [Google の公式料金表](https://ai.google.dev/gemini-api/docs/pricing)、[レート制限](https://ai.google.dev/gemini-api/docs/rate-limits)、AI Studio のプロジェクト課金状態を確認して、利用するモデルを選びます。無料枠・課金状態の確認欄にチェックし、設定を保存します。
6. **接続テスト**を押します。選択したモデルへ個人情報のない小さな構造化 JSON リクエストを送信し、「接続成功」と確認日時が表示されることを確認します。
7. 日・月・分単位の呼び出し上限、月間トークン上限、入力サイズと出力トークン上限を確認した後、**AI 機能**を ON にして保存します。
8. demoでは **AI模擬フォームの収集先を追加** → ダッシュボードの **今すぐ収集** で、10種類の明示されたテストデータを追加できます。テスト用プロフィールと応募同意を設定し、自動応募をONにした場合だけ応募ジョブを試せます。実際の賞品や実サイトへの応募ではありません。利用上限はモデル一覧・接続テストも消費します。複数ページはページごとの解析呼び出しが必要で、アプリの分単位上限に達した場合も手動確認へ移します。初期上限はGoogleの無料枠そのものではありません。

AI の ON と懸賞の自動応募 ON は別の設定です。実際の応募には、プロフィール、事前同意、カテゴリ、規約、対応する安全な通信範囲、重複・上限確認も必要です。接続テスト成功だけで自動応募を許可しません。

### キーの保管と優先順位

- Web 設定で本人が登録したキーを優先します。
- Web 設定にキーがない場合だけ、サーバーの `GEMINI_API_KEY` を利用します。
- どちらもなければ AI は未設定です。有料モデルや別プロバイダーへの自動切り替えはしません。
- **API キーを削除**は本人が保存したキーを削除し、AI 機能を OFF にします。環境変数のキーは削除されません。環境変数による利用も止めるには、サービス側の安全な環境設定で `GEMINI_API_KEY` を削除し、プロセスを再起動してください。

保存するキーは AES-256-GCM で暗号化し、利用者と API キー用の認証コンテキストを結び付けます。暗号化には API キーそのものを使いません。Supabase / Vercel / GitHub Actions には、既存の `PROFILE_ENCRYPTION_KEY` を同じ安全な値で設定します。ローカル demo は `.data/profile.key` を使います。既存のプロフィールや API キーがある状態で暗号鍵を変更・削除しないでください。

Supabase では本人の認証を API で確認し、キーを保存するテーブルはブラウザから直接読み取れない権限にします。GitHub Actions のワーカーはサーバー用資格情報と同じ暗号鍵で復号します。復号済みキーは UI・監査ログ・API レスポンスに返しません。

本番のキー登録・削除・設定変更は HTTPS が必要です。非公開のローカル demo のみ HTTP で試せます。demo モードをインターネットへ公開しないでください。

## 2. 使用量と無料枠

モデル ID の初期値は空です。過去のモデル名を固定したり、接続失敗時に別のモデルへ切り替えたりしません。モデル一覧は API の利用可否であり、無料対象モデルの料金表ではありません。モデル一覧 API から価格や無料残量を正確に得られないため、無料対象かどうかは上記の公式資料と本人のプロジェクト設定で確認します。

画面には今日・今月の呼び出し回数、入力・出力トークン数、成功・失敗件数、キャッシュ利用、直近のエラー、保留期間を表示します。日・月の境界は日本時間です。これらは**このアプリを経由したローカルのカウンター**で、Google 側の正確な残り枠ではありません。同じキーを別アプリから使った分は含まれません。

API を呼ぶ前に DB で予約し、複数ワーカーが同時に上限を超えないようにします。失敗したリクエストも呼び出し回数へ含めます。SDK が使用トークン数を返さなかった場合や応答不明時は、安全側の予約量を推定使用量として残します。

同じ利用者・モデル・解析内容のキャッシュを使い、同じ規約やフォーム構造を繰り返し送信する回数を減らします。キャッシュを使った処理と実際の API 呼び出しは区別します。キーやモデルが変わった場合は別のキャッシュとして扱います。

429 は次の明示的な試行まで60秒〜最大15分の指数バックオフで待機状態にし、タイムアウトや認証エラーも固定の安全なエラーとして記録します。勝手な再送・無制限のリトライはしません。指定上限を設定しても、有料プロジェクトへキーが移された場合や他アプリの利用まで含めて「課金ゼロ」を保証するものではありません。

## 3. Gemini に送る内容

送るのは、値を除いたフォームの入力種別・ラベル・選択肢、質問文、公開された商品情報・規約、個人を特定しない回答条件です。氏名、住所、電話番号、メールアドレス、生年月日、キー、Cookie、認証情報を送る入力形式は許可しません。登録プロフィールに一致する文字列も送信前にローカルで除去します。

入力済み DOM やスクリーンショットをそのまま再送信しません。複数ページでも、次ページの値を持たない構造だけを抽出し直します。画面に個人情報が混ざった場合は手動確認へ移す安全側の処理を優先します。現実の氏名などを含むスクリーンショットを障害報告に添付しないでください。

無料枠の送信コンテンツが Google のサービス改善に利用される可能性があります。現在の条件は [Gemini API の利用規約](https://ai.google.dev/gemini-api/terms)で確認し、秘密や個人情報を公開情報と混ぜないでください。

回答生成では購入・利用経験を作りません。クイズは取得した公開の根拠と照合し、答えを確定できなければ手動確認へ移します。任意の広告・メールマガジン同意はチェックしません。不明な必須項目、CAPTCHA、本人認証、購入・契約がある場合も自動送信しません。

## 4. 既存 Supabase とワーカーの更新

1. 既存 DB に `supabase/migrations/202610280002_ai.sql` を追加適用します。初期マイグレーションを消したり DB を作り直したりしません。
2. Vercel と GitHub Actions の `PROFILE_ENCRYPTION_KEY` が一致することを確認します。キーを作り直して合わせる方法は使いません。
3. Web UI で本人のキーを登録する場合、`GEMINI_API_KEY` を GitHub Secrets に追加する必要はありません。ワーカーが暗号化 DB から本人のキーを取得します。
4. 環境変数のフォールバックを使う場合だけ、サービス設定で `GEMINI_API_KEY` を安全に登録します。変数名に `NEXT_PUBLIC_` を付けません。
5. 自動応募は OFF のまま、モデル取得・接続テスト・利用量の増分を確認します。

実サイトの汎用操作は初期設定で無効です。運用者が `ENABLE_LIVE_SUBMISSIONS=true` と `LIVE_SUBMISSION_HOSTS` の完全一致ホストを設定し、情報源にも同じ公式ホストを許可することが前提です。さらに規約・プラットフォームの操作条件、通信先と本人同意を確認します。同一origin以外の通信は許可しません。地域・性別・職業・年齢上限など、現在のプロフィールとルールでは照合できない条件は手動確認へ移します。モデルが「許可」と回答しただけでは有効化しません。実サイトでの送信テストは行わないでください。

### 接続テストのコマンド

Web UI からの接続テストのほか、保存済みの本人設定を利用する CLI を用意します。

```bash
npm run test:gemini
```

CLI はプロセスの環境変数と DB を利用します。`.env.local` を自動で読む前提にはせず、必要な場合は Node.js の `--env-file` オプションを使ってください。キー全文やプロファイルを出力せず、成功・失敗と設定状態を報告します。

キー未設定、モデル未選択、無料枠未確認、ネットワーク拒否は、実 API の接続成功とは扱いません。モックを使う自動テストの成功とも区別します。

## 5. ネットワークと資料の確認状況

Gemini Developer API の送信先は `generativelanguage.googleapis.com` です。制限付きクラウド環境では、このホストの HTTPS 通信許可が必要です。公式資料を環境内から参照する場合は `ai.google.dev` も必要です。ネットワーク制限を外す、プロキシを迂回する、TLS 検証を無効にする方法は使いません。

2026年10月28日（日本時間）の実装作業では、次を確認しました。

| 公式資料                                                                                          | 確認状況                                                                    |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [Google 公式 JS SDK README](https://raw.githubusercontent.com/googleapis/js-genai/main/README.md) | 取得成功。サーバーでのキー管理と公式 SDK の `models.generateContent` を確認 |
| [Gemini API 料金表](https://ai.google.dev/gemini-api/docs/pricing)                                | 環境のプロキシが CONNECT 403 で拒否。本文未取得                             |
| [モデル資料](https://ai.google.dev/gemini-api/docs/models)                                        | 参照先を提示。本文未取得                                                    |
| [レート制限](https://ai.google.dev/gemini-api/docs/rate-limits)                                   | 参照先を提示。本文未取得                                                    |
| 実 API のモデル一覧・生成                                                                         | この環境に利用者の API キーが未設定のため未実行                             |

そのため、この資料は特定のモデル ID・Google の現在の無料上限・実 API 接続成功を断定していません。設定画面で本人のキーを登録し、現在の公式料金と利用可否を確認してから実利用を開始してください。

このクラウド環境のネットワーク設定には `ai.google.dev` と `generativelanguage.googleapis.com` を追加した下書きを保存しました。実行中環境にはまだ適用されていません。ここで実接続を試す場合は、環境設定で変更を確認・保存し、環境をPublishして反映後に接続テストを再実行してください。これはVercelへアプリを公開する操作とは別です。自分のPCから通常のネットワークで実行する場合、このクラウド環境の設定変更は不要です。
